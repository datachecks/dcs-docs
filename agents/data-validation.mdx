The Data Validation agent helps you set up validations without manually navigating configuration options. You describe what you want to check — the agent identifies the target table and validation type and generates the appropriate validation configuration.

## What it does

- Extracts the target table from your natural language description
- Identifies the relevant validation type (null checks, uniqueness, range checks, custom SQL, and more)
- Generates a validation configuration ready to enable on your asset

## How it works

The agent follows a three-step workflow:

```
User message
      ↓
Extract table
(identify which dataset the validation applies to)
      ↓
Extract validation type
(identify what kind of check to configure)
      ↓
Generate response
(return the validation configuration)
```

The agent maintains conversation state, so you can refine or follow up within the same session.

## Supported validation types

The agent can configure the following validation types:

| Type | Description |
|------|-------------|
| **NOT NULL** | Checks that a column contains no null values |
| **UNIQUE** | Checks that all values in a column are distinct |
| **CHECK** | Checks that column values satisfy a condition |
| **FOREIGN KEY** | Checks referential integrity between tables |
| **Custom SQL** | Validates data using a custom SQL assertion |
| **Delta Validation** | Checks the change between two time periods |

For a full list of supported validation types and their configuration options, see [Validation Types](/reference/validation-types).

## Example interactions

```
You: Check that the email column in the customer table has no nulls.

Agent: I'll set up a NOT NULL validation on customer.email.
       Here's the configuration: ...
```

```
You: Make sure all order IDs in the orders table are unique.

Agent: I'll configure a UNIQUE validation on orders.order_id.
       Here's the configuration: ...
```

## Prerequisites

Before using the Data Validation agent:

1. Your data source must be connected and added to your workspace.
2. The target datasets must be registered as assets. See [Assets](/assets/overview).

## Running the agent

1. In Bifrost, navigate to **Agent** in the left sidebar.
2. Start a new session in the Data Validation context.
3. Describe the validation you want to set up.
4. Review the generated configuration and confirm to enable it.

## Enabling the validation

After the agent generates a validation configuration, you can:
- Enable it directly from the agent session
- Navigate to **Assets** and enable it from the asset's validation list
- Review and adjust thresholds before enabling

See [Validation](/validation/overview) for details on managing validations after they are set up.
