The Stormbreaker API gives you programmatic access to all Datachecks operations — comparisons, validations, data sources, jobs, and more.

## Authentication

All API requests require a Bearer token and a workspace ID header:

```http
Authorization: Bearer <your-api-key>
Workspace-Id: <your-workspace-id>
```

You can create API keys under **Settings → API Keys**.

## Base URL

```
https://api.datachecks.io
```

## Versioning

The current API version is `v1`. All endpoints are prefixed with `/api/v1/`.
